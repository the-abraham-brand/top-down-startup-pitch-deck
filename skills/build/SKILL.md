# /top-down-startup-pitch-deck:build

Build a complete, source-backed pitch deck.

1. Load the `top-down-startup-pitch-deck` skill from this plugin (via the Skill tool) and follow it in **Build** mode. If it cannot be loaded, read `../top-down-startup-pitch-deck/SKILL.md` and its `references/` folder directly.
2. Take the company material from the text after the command, attached files (spec sheets, old decks, one-pagers) and the conversation. Decide the deck type: investor (default) or product (if the audience is prospects or customers).
3. If essentials are missing (what it does, for whom, the ask or offer, team, pricing), ask for them in one batched message; otherwise proceed and list assumptions.
4. Plan the research from the solution (product → problem → claims → who holds authoritative data in this industry and geography). Use only sources that pass the trust test, open each one, match every figure exactly, corroborate headline figures with a second independent source, and keep the sources ledger.
5. Share the storyline (the slide headlines in order), then build the deck in the design system, with source footers, a Sources slide and speaker notes.
6. Render and inspect every slide, fix any layout problems, then deliver: the deck, the storyline, the sources ledger, and open items.
